Search Paste from Excel

Copy a list of cells from Excel, paste it in the search bar of any view, and Odoo searches all the values at once.

Odoo Community Odoo Enterprise Odoo.sh

Why this app?

A customer sends a list of 30 order numbers, invoices or product codes in Excel... and Odoo searches one value at a time. With this app, copy the column, paste it in the search bar, pick the field: one filter finds every record of the list.

Features

Paste cells from Excel
Copy a column, a row or a whole block of cells from Excel, Google Sheets or LibreOffice and paste it in the search bar.
Or type with commas
Type several values separated by commas, e.g. S00002, S00006, Arabic comma included.
Pick the field
The search bar proposes every field that can hold all the values: references, customers, products, numbers, dates...
One filter, exact match
All the values go in one facet combined with "or". Each value is an exact match, not case sensitive: 100 does not find 1000.
Every view, every app
List, kanban, pivot, graph... Sales, Invoicing, Inventory, Contacts or your own models: it works wherever there is a search bar.
Zero configuration
Install the app and paste. Empty cells and duplicates are ignored, one pasted value keeps the standard search.

See it in action

1Paste a column of order numbers

The pasted cells are kept in the search bar, and every field that can hold them is proposed.

2All the orders in one filter

Choosing Order adds one facet with the 4 values: exactly the 4 orders of the list are found.

3Type values separated by commas

No spreadsheet at hand? Type the values with commas between them.

4Search them in any field

Choosing Customer finds the orders of the 3 customers at once.

Installation

1. Download

Put the web_search_paste folder in your addons path.

2. Install

Update the apps list and install Search Paste from Excel.

3. Done

No settings: paste a list in any search bar.
